# Examen Final - Diseño Web

Se han cumplido con todos los requisitos funcionales solicitados (tienda, carrusel, categorización múltiple y responsividad), aplicando tecnologías modernas para garantizar un producto de calidad profesional:

* **Tailwind CSS (Reemplazo de Bootstrap):** Utilizado para construir un diseño 100% a la medida, limpio, responsivo y sin las limitaciones gráficas de las librerías tradicionales.
* **Angular 18+ y Signals (Reemplazo de jQuery):** Se prescindió de jQuery por ser una tecnología *legacy*. Se aplicó la reactividad nativa de Angular (Standalone Components + Signals) para que el filtrado múltiple del catálogo actualice el DOM de forma inmediata y sin cuellos de botella en el rendimiento.
* **Valor Agregado:** Se incluyeron animaciones por CSS nativo (*smooth scrolling*, *hovers* y transformaciones) junto con imágenes de productos generadas por IA para dotar al proyecto de una estética *premium*.
